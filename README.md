THALVARA — a travel poster for a place that isn't there. A pure-Python program (standard library only, no network) draws a 1024x1024 sunset poster of an invented lagoon island crowned by the Skyglass Spire, a crystal tower catching the last light while paper lanterns drift on the water, with the island's name set in large hand-drawn lettering. The PNG is written byte-identically on every run.

## Run it

```sh
python3 main.py
```
